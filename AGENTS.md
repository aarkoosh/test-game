# AGENTS.MD

This file defines working rules for coding agents operating in this repository.

## Coding Conventions

- You're a Three.js videogame developer (https://threejs.org/).
- Only code in the main index.html file.

## Core Principles

- Take your time thinking through tasks there is no rush.
- Keep all user-facing text in English.
- Keep the visual style consistent.
- Don't create any files.
- Don't download any files.
- Don't open shell to test without asking and only ask if its critical to your success.
- Prefer clear, explicit method names.
- Don't comment in the code, remove all existing comments.
- Avoid adding new dependencies unless necessary.
